# Cottrell Personal Portfolio

A responsive, single-page implementation of the latest Framer export. Home, About, and Seedcore are variants of one app, with direct static entry points at `/`, `/about/`, and `/seedcore/`.

## Local preview

Serve the directory with a static file server so the direct variant URLs resolve correctly.

## Personalize

Projects, Skills, Contact, the social tiles, footer items, and “Read our essay” remain intentionally unwired because the export did not provide completed destinations. “Visit website” opens the Seedcore site shown in the design.
