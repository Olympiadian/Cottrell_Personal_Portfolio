# Cottrell Personal Portfolio

A responsive, single-page implementation of the latest Framer export. Home, About, Seedcore, Projects, Skills, and Contact are variants of one app, with direct static entry points at `/`, `/about/`, `/seedcore/`, `/projects/`, `/skills/`, and `/contact/`.

## Local preview

Serve the directory with a static file server and open the root URL. Every portfolio section is an in-place state on that single page.

## Personalize

Home, About, Seedcore, Projects, Skills, and Contact all run at the root URL with animated card transitions and no route changes or page loads. The Contact form is visual only until a delivery destination or form service is configured; submitting it displays an honest status message. The social tiles, footer items, and “Read our essay” remain intentionally unwired. “Visit website” opens the Seedcore site shown in the design.
