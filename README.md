# Cottrell Personal Portfolio

A responsive, single-page implementation of the latest Framer export. Home, About, Seedcore, Projects, Skills, and Contact are variants of one app, with direct static entry points at `/`, `/about/`, `/seedcore/`, `/projects/`, `/skills/`, and `/contact/`.

## Local preview

Serve the directory with a static file server so the direct variant URLs resolve correctly.

## Personalize

Projects, Skills, and Contact have navigable in-progress variants because the export did not provide completed content for them. The social tiles, footer items, and “Read our essay” remain intentionally unwired. “Visit website” opens the Seedcore site shown in the design.
